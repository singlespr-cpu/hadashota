# חדשותא — V69 Recovery

גרסה זו מחזירה את מבנה הפריסה שעבד לפני V68 ולא כוללת `wrangler.jsonc`.

## העלאה לפרויקט הקיים
1. העלו את כל קבצי V69 לאותה תיקייה ב-GitHub שבה נמצאים `index.html`, `app.js` ו-`_worker.js`.
2. **חשוב:** אם נשאר ב-GitHub הקובץ `wrangler.jsonc` מ-V68 — למחוק אותו ידנית. העלאת ZIP חדש אינה מוחקת קבצים ישנים שאינם קיימים ב-ZIP.
3. אין לשנות ב-Cloudflare את Build command, Root directory, Worker entry point או Static Assets binding. V69 מיועדת להשתמש בהגדרות הפריסה שכבר עבדו בפרויקט לפני V68.
4. לאחר הפריסה, בתחתית דף הבית אמור להופיע `גרסה V69 · API V69`.
5. אם מופיע `גרסה V69 · API לא מחובר`, הקבצים הסטטיים עלו אך `/api/health` אינו מגיע ל-`_worker.js`; במקרה כזה צריך לבדוק את הגדרת ה-Worker הקיימת ב-Cloudflare ולא לשנות את קוד האתר.

## איסוף חדשות
- 45 מקורות מוגדרים בסך הכול: 24 אתרים/מקורות רשמיים ו-21 ערוצי Telegram.
- בכל איסוף shard מתבצע מעבר ראשון על **כל** המקורות באותו shard לפני retry כלשהו.
- concurrency נשאר 6 כדי לא לעבור את מגבלת החיבורים המקבילים של Cloudflare Workers.
- רענון ידני, רענון foreground והרענון האוטומטי מפעילים איסוף fresh; התוצאה הראשונה שמגיעה מאחד ה-shards יכולה להצטייר לפני שהשני סיים.
- מקור יחיד אינו יכול להפוך לסיפור המרכזי. 3+ מקורות קודמים; ירידה ל-2 מותרת רק לפי מדיניות השעה המוגדרת בלקוח.

## בטיחות פריסה
V69 לא משנה את תצורת Cloudflare. אין `wrangler.jsonc` בחבילה בכוונה.
