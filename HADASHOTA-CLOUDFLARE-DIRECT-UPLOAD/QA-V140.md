# QA — כותרת פלוס V140

## מדד ההסלמה
- עמוד `/escalation` עצמאי, RTL ורספונסיבי.
- מד עגול 0–100, רמת מתיחות, מגמה ל־6 שעות וגרף 72 שעות.
- הבהרה קבועה: המדד אינו הסתברות למלחמה ואינו תחזית מודיעינית.
- 8 סיגנלים: חדשות כותרת פלוס, פיקוד העורף/רשמי, תעופה מעל איראן, NOTAM, Brent, עמדה אמריקאית, UKMTO, Polymarket.
- מדד פיצה (PizzINT) מוצג כניסיוני עם 0% משקל.
- מקורות חסרים מוסרים מהחישוב; נתון שמור זמנית מקבל חצי משקל בלבד.
- תעופה לומדת קו בסיס היסטורי בתוך Durable Object ומחפשת ירידה חריגה בתנועה.
- רענון API גלובלי ננעל כדי למנוע כפילות; מקורות חיצוניים כבדים מתרעננים לכל היותר אחת ל־15 דקות.
- עמוד הבית מציג טיזר דק; בדסקטופ נוסף גם קישור בניווט, ובמובייל הקישור בניווט מוסתר כדי לא ליצור צפיפות.
- SEO: canonical, OG/Twitter דינמיים לפי הציון האחרון, sitemap.
- Footer מקשר חזרה לכותרת פלוס המלא.
