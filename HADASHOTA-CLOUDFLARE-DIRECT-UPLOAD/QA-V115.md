# V115 — Editorial Redesign

Design-only release based on V114.

## Visual changes
- Main story is the clear editorial focal point: larger original image, stronger headline, less card-like chrome.
- Feed changed from floating cards to a denser newsroom list with separators.
- Generic feed preview copy is visually removed; source/time/title carry the hierarchy.
- Subtle category rails remain as the recurring Koteret Plus visual signature.
- Filter panel and live-status strip are flatter and quieter.
- Mobile feed shows materially more stories per screen.
- Dark mode receives matching editorial treatment.

## Functionality intentionally unchanged
- V114 original article image-first logic retained.
- V113 live lead refresh retained.
- V112 instant-paint snapshot retained.
- 30-second refresh retained.
- Admin/promotions/settings/filters/sidebar remain.
- Existing live-data and media cache namespaces are preserved.

## Static QA
- JavaScript syntax: app.js, _worker.js, sw.js — passed.
- Duplicate HTML IDs: none.
- Static button IDs without app.js references: none.
