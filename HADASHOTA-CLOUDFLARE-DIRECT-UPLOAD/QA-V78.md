# כותרת פלוס V78 — מיתוג + SEO

## מיתוג
- שם חדש: כותרת פלוס
- סלוגן: כל החדשות. כל המקורות. במקום אחד.
- עודכנו דף הבית, אודות, איך זה עובד, יצירת קשר, פרטיות, זכויות יוצרים, PWA/manifest וטקסטים גלויים.
- שמות משתנים, מזהי קוד ומפתחות localStorage/cache פנימיים מסוג hadashota.* נשמרו כדי לא לשנות התנהגות או לאפס משתמשים.

## SEO
- title ותיאור ממוקדים לדף הבית.
- title + description ייחודיים לכל עמוד מידע.
- Open Graph + Twitter metadata.
- WebSite + Organization JSON-LD עם השם החדש.
- robots index/follow.
- keywords רלוונטיים באופן מתון, ללא keyword stuffing.
- sitemap ו-robots הקיימים נשמרו.
