# V124 — Redirect Loop Fix + True Push

## Root cause fixed
V123 introduced a new wrangler.jsonc for Durable Object + Cron, but the static-assets configuration omitted:
- html_handling: "none"

Cloudflare's default HTML handling can canonicalize /index.html to /.
The Worker intentionally serves / by internally fetching /index.html, so that default behavior could create:
/ -> internal /index.html -> redirect / -> internal /index.html ...

## Fix
- assets.html_handling = "none"
- assets.not_found_handling = "none"
- run_worker_first remains true
- ASSETS binding remains unchanged

## Preserved
- True Web Push Durable Object
- 1-minute Cron
- VAPID/server push logic
- V121 Google verification / SEO
- V122 right-side back-to-top arrow
- Existing news sources, refresh logic, images and admin
