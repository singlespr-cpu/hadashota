# V112 — Instant Paint

Root cause addressed:
- On a browser tab discard/cold resume, V111 rebuilt clusters from six local shard
  snapshots synchronously before first paint.
- V112 stores an already-merged compact render snapshot after each successful update.
- Cold resume restores that snapshot directly with no clustering/network dependency.

Resume behavior:
- Existing page paints first.
- Forced fresh-source fetch begins ~340–380 ms later.
- Utilities/alerts are delayed behind first paint.
- Premium MutationObserver work runs during idle time and no longer watches the
  entire feed subtree.
- Offscreen feed cards use CSS content-visibility.

Production invariants:
- 30-second forced refresh retained.
- Image context protections retained.
- Duplicate IDs: none
- Unreferenced static button IDs: none
