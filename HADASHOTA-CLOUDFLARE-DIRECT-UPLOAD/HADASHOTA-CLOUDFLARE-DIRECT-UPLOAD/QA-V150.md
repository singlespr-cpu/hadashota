# Koteret Plus V150 — Push Center + Admin Analytics

Baseline: V149 (`KOTERET-PLUS-FINAL-V149-BACK-TO-TOP.zip`).

## What changed
- True Web Push infrastructure retained and expanded; no rebuild of the existing VAPID/Durable Object stack.
- Hot-story push now waits for a stable qualified lead across two scheduled checks (~45–60s minimum) before sending.
- Automatic escalation push: upward threshold crossing 50/70/85 or +10 points within ~1h with multi-domain corroboration; cooldown prevents repeated alerts.
- Manual push to all subscribers from the secret admin page.
- Admin-device subscription + test-push-to-self.
- Per-device pending notification mapping, so manual/test/escalation/hot-story pushes resolve to the intended notification even when the site is closed.
- Fixed subscription stats double-counting from the previous implementation and added V150 stats self-heal by recounting actual subscription rows.
- Push opt-in offer updated on the main site and added to `/escalation`.
  - No prompt when permission is denied.
  - No prompt when already enabled.
  - "Not now" snoozes for 14 days.
  - iOS explains Home Screen installation requirement.
  - Existing granted subscriptions are repaired in the background.
- Old copy saying notifications only work while the site/PWA is active was removed.
- Admin route `/manage-kp-7538` keeps the existing username/password hash and promo tools, now with a full dashboard.
- First-party analytics added via the existing Durable Object:
  - total page views
  - home / escalation / info-page views
  - daily unique device hashes
  - 14-day chart
  - accumulated peak hour in Asia/Jerusalem
  - device and referrer groups
- `/escalation` footer now shows a persistent all-time escalation page-view counter.
- Analytics starts when V150 is deployed; it is not retroactive.
- Existing duplicate `async async function` declarations in the V149 Worker were normalized to valid module syntax without changing their logic.
