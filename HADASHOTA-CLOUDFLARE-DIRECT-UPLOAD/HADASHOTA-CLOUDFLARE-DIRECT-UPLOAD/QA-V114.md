# V114 — Original Article Images First

Image priority is now:
1. Exact image already supplied by the original RSS/JSON-LD/Telegram item.
2. Exact article page probe: og:image / twitter:image / JSON-LD / article image.
3. Strict reusable contextual image only when the first two paths fail.
4. Clean contextual placeholder if no safe match is found.

Changes:
- Added /api/source-image with a strict allowlist derived from configured news-source hosts.
- The endpoint never fetches arbitrary third-party hosts supplied by the browser.
- Article-page image results are edge-cached.
- Photo credit is extracted where available and returned with the original image.
- Lead story now uses original article imagery before Commons/Openverse.
- Feed cards without an RSS image probe the exact article before using an illustration.

Regression QA:
- Node syntax checks: app.js, _worker.js, sw.js.
- Duplicate IDs: none
- Unreferenced static button IDs: none
- V113 live lead refresh, V112 instant paint, 30-second scheduler, filters, settings, ads/admin and image-context guards retained.
