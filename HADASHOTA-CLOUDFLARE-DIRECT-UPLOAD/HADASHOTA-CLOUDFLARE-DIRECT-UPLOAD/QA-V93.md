# כותרת פלוס V93 — Licensed Media Only

## Source article images
A source/article image is no longer trusted merely because an RSS/Telegram/news
payload contains imageUrl. It is displayed only when the payload also contains
an explicitly reusable license:
- CC0
- Public Domain
- CC BY
- CC BY-SA

For attribution-required licenses, creator + license URL are mandatory.
Without that metadata the original source image is rejected.

## Alternative images
- Wikimedia Commons only.
- Existing strict semantic relevance gate remains.
- Openverse fallback disabled.
- Old media cache namespace changed, so prior Openverse selections are not reused.
- Attribution links to the Commons file/source page.

## No safe relevant image
The existing contextual Koteret Plus branded fallback is used. No random photo
is substituted.

All V92/V91 news, ranking, ads, refresh and UI behavior is preserved.
