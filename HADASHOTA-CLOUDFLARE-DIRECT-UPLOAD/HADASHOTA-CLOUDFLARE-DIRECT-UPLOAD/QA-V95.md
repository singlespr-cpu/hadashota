# V95 Strict Image Matching
- Wrong image is treated as worse than no image.
- Sea/rescue stories reject road/motorcycle imagery.
- Road, fire, security and political contradictions are also rejected.
- Main lead is strictest: event-heavy stories require matching visual context.
- Original article images still require explicit reusable-license metadata.
- Wikimedia Commons remains the only automatic external image source.
- If no safe relevant image exists, the Koteret Plus contextual fallback is used.
- Old media cache namespace changed so mismatched cached images are not reused.
- No other site behavior changed.
