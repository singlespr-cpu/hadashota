# V94 Better Licensed Images

- Source/article images remain blocked unless explicit reusable-license metadata exists.
- Wikimedia Commons remains the only automatic external image source.
- Media search now tries several legal/relevant variants:
  person name, place/entity, organization, then the full semantic query.
- Feed relevance threshold relaxed moderately for portraits/places while still requiring
  a licensed Commons result and actual query overlap.
- Lead image remains stricter than feed images.
- Openverse remains disabled.
- Old "חדשותא" fallback text replaced by "כותרת פלוס".
- When no suitable licensed image exists, a branded contextual tile is shown instead of a blank gray square.
- No other site logic changed.
