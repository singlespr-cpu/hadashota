# V97 Richer Safe Images

Goal: materially increase image coverage without returning to unrelated imagery.

- Wikimedia Commons remains first choice.
- Commons candidate pool increased to 36.
- Commons relevance threshold lowered, while negative context matching remains.
- Client can accept same-context illustrations with lower literal token overlap.
- Safe-media request budget increased.
- More query variants may be attempted per story.
- Openverse is re-enabled only for CC0 / Public Domain results.
- CC BY / CC BY-SA Openverse results remain excluded.
- Source-article images still require explicit reusable-license metadata.
- Context contradictions remain blocked (sea rescue vs motorcycle/road, etc.).
- Contextual images are labelled "תמונת המחשה".
- New media cache namespace prevents V96 no-image results from sticking.
- No other site behavior changed.
