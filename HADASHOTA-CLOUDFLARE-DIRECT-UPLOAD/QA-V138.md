# V138 — Stable Original Article Images + System QA

## Image stability
- Feed images survive 30-second DOM rerenders through an in-memory article-image map.
- Already loaded source images are captured before a feed rebuild and restored immediately.
- Exact linked article imagery (/api/source-image) upgrades RSS imagery without blanking the currently visible image.
- Failed image URLs are temporarily quarantined so they do not retry-loop forever.
- Client-side negative article-image results expire after 45 seconds instead of being pinned for the session.
- Worker negative source-image cache reduced from 7 minutes to 45 seconds and cache namespace bumped.
- Cluster cards no longer borrow an image from another article/report in the same cluster.
- Filtered source-kind cards no longer inherit the cluster representative's unrelated image.

## Additional bugs fixed during full audit
- Removed a stale unmatched closing </section> fragment from index.html; all HTML pages now parse without structural errors.
- renderBreaking() now exits safely when the legacy breaking-banner markup is absent instead of throwing during each render cycle.
