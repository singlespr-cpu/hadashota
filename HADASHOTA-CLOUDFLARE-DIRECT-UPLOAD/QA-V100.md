# V100 — Photo Credits

When a feed item uses the original image supplied by the source:
- The worker attempts to identify the photographer/credit from:
  - JSON-LD (creditText / creator / copyrightHolder / ImageObject)
  - image/credit meta tags
  - text near the exact image URL/filename
  - common labels: צילום / צלם / קרדיט / Photo / Credit
- If found, the feed shows:
  צילום: [name] / [source]
- If no reliable photographer is found:
  מקור תמונה: [source]

Licensed Commons/Openverse attribution remains unchanged.
No other site behavior was intentionally modified.
